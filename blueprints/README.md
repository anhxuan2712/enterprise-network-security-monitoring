# ARCHITECTURAL BLUEPRINTS & CAD DRAWINGS

Thư mục lưu trữ các bản vẽ kỹ thuật mặt bằng, bố trí thiết bị phòng ban và tủ mạng của doanh nghiệp TechCorp (Tòa nhà A & B).

---

## 📂 Danh mục tệp

1. **`index.html`**:
   - Giao diện web tương tác mô phỏng mặt bằng chi tiết 26 phòng ban thuộc 2 tòa nhà A (5 tầng) và B (4 tầng).
   - Hiển thị vị trí tủ mạng IDF, phòng máy chủ MDF A-202, các vị trí đặt switch, camera, điểm truy cập Wi-Fi (AP) và máy trạm.
   - Hướng dẫn xem: Mở trực tiếp file `index.html` bằng bất kỳ trình duyệt web nào (Chrome, Edge, Safari, Firefox).

2. **`floorplans-archive.pdf.bz2`**:
   - File nén chứa các bản vẽ kỹ thuật mặt bằng từng phòng ban định dạng PDF độ phân giải cao.
   - Giải nén bằng lệnh:
     ```bash
     bzip2 -d -k floorplans-archive.pdf.bz2
     ```
